# Gabarit du brief hebdo (mail Gmail, HTML simple)

Objet : `Veille Bellangé — semaine du JJ/MM : N nouveautés` (ou `: rien de neuf`). Déposé en **brouillon** Gmail (create_draft), pas envoyé.

Ton : sobre, factuel, tutoiement. Pas d'emoji. Chaque item = une ligne avec lien. Prix tels qu'affichés. Le mail doit se lire en 60 secondes ; la page a le détail.
